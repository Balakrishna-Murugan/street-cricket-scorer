3) GitHub Actions & CI — Quick cheatsheet

Common workflow tasks you'll include in a CI workflow for this repo. Below are common commands and an example CI job snippet.

Common commands (CI)
  • actions/checkout@v3 — check out repository code in CI runner.
  • actions/setup-node@v4 — set Node.js version for the job.
  • npm ci --prefix client — install client deps reproducibly from package-lock.
  • npm run build --prefix client — build the client production bundle.
  • npm ci --prefix server & npm test --prefix server — install and test server code.
  • Use actions/cache to cache node_modules between jobs for faster runs.
Example job snippet 
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-node@v4
        with:
          node-version: '18'
      - run: npm ci --prefix client
      - run: npm run build --prefix client
      - run: npm ci --prefix server
      - run: npm test --prefix client --silent
      - run: npm test --prefix server --silent

4) Terminal & Git cheat sheet (React + Node)

Local dev (client)

npm install — install dependencies (run once or when package.json changes).
npm start — start the CRA dev server (hot reload, usually on localhost:3000).
npm run build — produce an optimized production bundle in client/build.
npm test — run Jest tests (interactive by default with CRA).

Server

cd server — change to server folder.
npm install — install server dependencies.
npm run build — compile TypeScript to dist/ (if configured).
npm start — run the compiled server (node dist/index.js).
npm run dev — start a dev runner (ts-node-dev) with auto-reload for local development.
npm test — run server tests (Jest).

Commands explained — GitHub / React / Node.js

Git & GitHub (terminal)

  • git checkout -b feature/my-feature — create & switch to a new branch for your work.
  • git add -A — stage all changed files for commit.
  • git commit -m "feat: description" — commit staged changes with a message.
  • git push --set-upstream origin feature/my-feature — push branch to remote and set upstream tracking.
  • git pull --rebase — update local branch with remote changes, rebasing your commits on top.
  • gh pr create --fill (GitHub CLI) — open a Pull Request from the current branch (fills title/body from commit message).

React (client)

  • npm install — installs client dependencies.
  • npm start — runs the create-react-app dev server with fast refresh.
  • npm run build — creates the production static bundle to deploy (in client/build).
  • npm test -- --watchAll=false — run tests once (non-interactive), useful in CI.
  • npm run eject — eject CRA config (irreversible); only use if you need to control webpack/ babel yourself.

Node / Server

  • cd server — move into server project.
  • npm install — install server deps.
  • npm run build — compile TypeScript (produces dist/ files).
  • npm start — run the compiled server (node dist/index.js).
  • npm run dev — run server in dev mode with auto restart (uses ts-node-dev in this repo).
  • curl -X POST http://localhost:5000/api/docs/docx -H "Content-Type: application/json" -d "{ \"html\": \"...\" }" --output out.docx — example for testing the docs conversion endpoint from terminal.
